Le barde est une classe très particulière, qui inflige peut de dégâts directs ; elle se spécialise dans les buffs/débuffs et les interactions sociales. 
Le barde a une caractéristique unique, la porté de voix, qui est de (5+CON/2), celle ci est utilisée comme portée/rayon pour la plupart de ses compétences, comme l'inspiration, par exemple, le barde peut essayer de faire porter cette voix plus loin, devant réussir un jet de CON dont la difficulté augmente de 5/m, à l'inverse, un millieu bruyant (un champs de bataille par exemple) pourra réduire cette porté en cas d'échec d'un jet de CON, qui dépendra du niveau de bruit de l'environnement

Caractéristique principale : Charisme
Caractéristique secondaire : Con
Dé de PV : 1d4
Dé de PE : 1d4

Il faut avoir +10 en Charisme pour multiclasser Barde.
