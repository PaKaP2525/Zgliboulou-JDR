Il y a plusieurs types d’actions en combat ; les compétences utilisent des actions pour être utilisées. Il est important de maîtriser ce concept pour combattre efficacement.

L’action simple est l’action principale de votre tour. Attaquer est une action simple, par exemple. Vous pouvez faire à peu près ce que vous voulez par une action simple, mais vous n’en avez qu’une par tour (sauf exception).

L’action rapide est la petite soeur de l’action simple. Vous n’en avez également qu’une par  tour, mais elle ne permet que de faire certaines actions précises. Les compétences qui utilisent une action simple le précisent.

L’action de déplacement permet de se déplacer (duh), mais elle est parfois remplacée par autre chose (par des compétences spécifiques).

L’action bonus est un peu particulière ; elle est comme l’action rapide, mais elle n’est pas limitée à une seule utilisation. Si deux compétences permettent l’utilisation d’une action bonus, on peut faire les deux le même tour (contrairement à l’action rapide).

La réaction est une action que l’on effectue pendant le tour de quelqu’un d’autre. Par exemple, si on vous attaque, vous pouvez essayer d’esquiver l’attaque en réaction. On a un nombre illimité de réactions.

Voici une liste non exhaustive de certaines actions et de leur type : 

Attaquer en combat : Action simple
Se déplacer : Action de déplacement
Encocher une flèche : Action rapide
Boire une potion en entier : Action simple
Boire une potion vite (donc uniquement recevoir des effets partiels) : Action rapide
Utiliser une compétence : Ca dépend de la compétence :)
